# Между строк

A personal story reader presented as a conversation. Russian UI. A quiet white reading surface, familiar blue and grey chat bubbles, avatars in header or alongside messages. The editor uses a three-column workspace: chapters, script, live page preview.

Palette: paper #FFFFFF, canvas #F0F3F8, ink #192535, muted #68778B, message blue #087FF5, reply grey #E9EBEF. Segoe UI Variable / Segoe UI for readable Russian text. Headings use the same face with moderate weight. 15px controls, 17px messages, 30px page titles.

Reader: compact navigation rail, chapter introduction, central conversation page with generous margins, deliberate page ending, bottom progress and previous/next controls. Vertical mode preserves page divisions. Editor: chapter rail | editable message list | same chat component as reader.

The distinctive detail is the page ending: a small trailing typing indicator and a page-turn control after the final bubble. Timed chapters use a sealed message envelope with countdown, opening when the timestamp arrives. No distracting motion elsewhere. Reduced-motion supported.

Review: the visual direction matches the supplied iMessage-like example; no decorative dashboard cards or marketing hero. Long messages scroll inside the page rather than shrinking text to force seven messages to fit.

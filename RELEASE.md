Первая версия «Между строк» для Windows x64.

Установите `BetweenLines-Setup-1.0.0.exe`. В приложении есть читалка и редактор с предпросмотром: страницы переписки, два направления чтения, PNG-аватарки, цвета, границы страниц, публикация глав и открытие по таймеру. Для чтения вход не нужен.

Новые главы загружаются отдельно от приложения. Обновления программы устанавливаются после подтверждения.

Установщик не имеет коммерческой цифровой подписи.
